# CErulean

Windows Mobile 5.0 / 6 をブラウザで動かすエミュレータです。
タップやキーで操作でき、対応アプリのインストールもできます。

**OS イメージは同梱していません。** [取得・抽出手順と利用条件](docs/images.md)を参照してください。

## 起動する

Web 資材を含む単体バイナリなら、Rust・Node.js・外部の Web 資材は不要です。

```sh
cerulean serve
```

1. <http://127.0.0.1:8000/app/> を開く。
2. 抽出した `.bin` を選んで起動する（画面サイズはファイル名から自動判定）。
3. Today 画面が出たら、タップ・ドラッグ・方向キー・Enter で操作する。PC の英数字入力は IME をオフにする。

### 基本操作

- **保存・再開:** 自動保存され、次回は「続きから再開」。メニューから手動保存・書き出しも可能。
- **音声:** メニューの「音を出す」でオン（等速時のみ）。
- **ストレージカードの操作:** メニューの「ストレージカード」でカードを作り、抜いた状態でファイルを入れて挿す。
  ファイルエクスプローラで、対応する `.cab` を開いてインストールするか、`.exe` を実行する。
- **環境の切り替え:** 起動画面のプロファイルで、イメージや保存状態を使い分ける。
- **オフライン:** ホーム画面への追加（PWA）に対応。読み込み済みの環境はオフラインでも利用可能。

保存先はブラウザ内です。サイトデータを消すと保存も失われます。
**書き出したスナップショットには OS の内容が含まれるため、公開共有しないでください。**

### ネットワークを使う

```sh
cerulean serve --with-relay
```

1. 起動時に表示される URL を開く（中継トークンが自動で設定される）。
2. メニューの「ネットワーク（中継サーバー経由）」をオンにする。
3. Windows Mobile の「設定 → 接続 → ネットワークカード」で、接続先を「インターネット設定」にする。
4. HTTPS を使う場合は、IE Mobile で `http://10.0.2.2/` を開き、CErulean Local CA をインストールする。

別の中継サーバーを使う場合は、メニューで URL とトークンを指定します。
HTTPS のページからは `wss://`（ローカルの中継は `ws://127.0.0.1`）を使います。

### サーバーのオプション

| オプション | 用途 |
|---|---|
| `--port 8080` | ポートを変更（既定は `127.0.0.1:8000`） |
| `--listen 0.0.0.0:8080` | 待ち受けアドレスとポートを変更 |
| `--with-relay` | ネットワーク中継を起動 |
| `--token TOKEN` | 中継トークンを固定（省略時は自動生成） |
| `--allow-private` | 中継から LAN・localhost への接続を許可 |
| `--root DIR` | 埋め込み資材の代わりに外部の Web 資材を配信 |

他の端末から使う場合は、HTTPS のリバースプロキシ経由で配信してください。

## ビルド・配信

### ソースからビルド

rustup、C コンパイラ、Node.js を用意し、リポジトリ直下で実行します（Windows は WSL の Bash）。

```sh
cargo install wasm-bindgen-cli --version 0.2.129 --locked
bash tools/build.sh
target/release/cerulean serve
```

### 静的な Web サーバーに置く

```sh
cerulean web-export site
```

`site/` の中身をそのまま HTTPS の Web サーバーに置き、`/app/` を開きます。
`.wasm` は `application/wasm` で配信してください。OS イメージは利用者が手元で選びます。
**ゲストのネット通信が不要なら、中継サーバーも CErulean の常駐プロセスも不要です。**

## できること

- WM5 / WM6 の対応イメージの起動・操作
- 標準アプリの利用、対応アプリの追加インストール
- 保存・再開、音声、ストレージカード
- PWA・オフライン起動、中継経由のインターネット接続

## 制限

- 実機用 ROM・Windows Phone・デスクトップ Windows は対象外
- 通話・SMS・携帯回線は未対応
- すべてのアプリや周辺機器の動作は保証なし
