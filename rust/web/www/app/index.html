      保存
      
    
      
      
      
    
      
    
        
    
        自動保存は 3 世代（起動が Today に着いたとき・画面を離れたとき・操作があれば 30 秒ごと・なければ 5 分ごと）。
      書き出したスナップショットにはイメージ（Microsoft の配布物）の中身が含まれます。公開の場で共有しないでください。
        
    
        
  
        
  
        
    
        ストレージカード
        
    
        -
        
    
        
      
      
      
      
    
        
    
        
      
      
    
        
    
        
      
        
        
        
        
        
      
        
      
          
      
          ここにファイルをドラッグしても入れられます。
          
    
          
    
          WM5 からは「Storage Card」に見えます。中身の出し入れは、カードを抜いている間に
      ここで行います。挿している間の中身はエミュレータの中にあり、保存（スナップショット）にも含まれます。
      抜くとこの端末に書き戻します。ネットワークがオンの間（PC カードのソケットをイーサネットカードが
      使っている間）は、Device Emulator のフォルダ共有の方式で挿します（WM5 からは同じ「Storage Card」）。
          
  
          
  
          
    
          ネットワーク（中継サーバー経由）
          
    
          
      
    
          
    
          
      
    
          
    
          
      
    
          
    
          オフ
          
    
          オンにしたときだけ、ここで指定した中継サーバーと WebSocket で通信し、WM5 の通信
      （TCP のバイト列と接続先の名前）を中継させます。オフの間、このサイトは外部と通信しません。
      中継サーバーは cerulean relay（ネイティブの CLI）で起動し、表示されたトークンを入れます。
      https のページからは wss:// の中継サーバー（または自分の端末の ws://127.0.0.1）にしかつなげません。
          
    
          HTTPS: WM5 の IE Mobile は古い TLS しか話せないので、エミュレータの中で TLS を
      受けて、外へは中継サーバーが今の TLS でつなぎ直します。最初に一度、WM5 の IE で http://10.0.2.2/ を開き、
      証明書（CErulean Local CA）をインストールしてください。この CA の鍵はこの端末の中だけにあります。
      
          
    
          初めて使うときは WM5 の「設定 → 接続 → ネットワークカード」で「ネットワークカードの接続先」を
      「インターネット設定」にしてください。オンの間もストレージカードは挿せます（フォルダ共有の方式になる）。
      受け取ったデータは操作の記録に含まれます。
          
  
          
  
          
    
          操作の記録
          
    
          
      
      
      
      
    
          
    
          記録は起点のスナップショットと、絶対命令数の入力スクリプトの組です。
      書き出した 2 つをネイティブの CLI で再生すると同じ画面になります（手順はスクリプトの先頭のコメント）。
