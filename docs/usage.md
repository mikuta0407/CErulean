# 詳しい使い方

[README に戻る](../README.md)。

## まず動かす

[Releases](https://github.com/mikuta0407/CErulean/releases) から、使用する環境に合うビルド済みバイナリを取得・展開してください。
`cerulean` のあるフォルダで実行します。

```sh
./cerulean serve
```

Windows では `cerulean.exe` を使い、PowerShell で `./cerulean.exe serve` を実行します。
ブラウザで <http://127.0.0.1:8000/app/> を開き、[取得・抽出手順](images.md)で用意した `.bin` を選択してください。
初回の起動には数十秒以上かかります。

サーバーを動かしているターミナルは開いたままにします。終了は Ctrl+C です。
実行権限がない場合は `chmod +x cerulean` を実行してください。

### ソースからビルドする場合

ソースから作る場合、以下のコマンドを、このリポジトリのルートで実行してください（Linux / macOS の Bash、
Windows では WSL の Bash を想定）。

必要なもの:

- rustup（Rust は `rust-toolchain.toml` の **1.98.1**、wasm ターゲットも自動で導入）
- C コンパイラとリンカー（Linux / WSL は GCC または Clang、macOS は Xcode Command Line Tools）
- Node.js（開発時は 24 LTS を使用）
- wasm-bindgen-cli **0.2.129**（このリポジトリの wasm-bindgen と同じ版）
- [対応する OS イメージ](images.md)

```sh
# 初回のみ。rustup と Node.js を用意した後、指定された Rust で CLI を導入
cargo install wasm-bindgen-cli --version 0.2.129 --locked

# Web 資材を生成し、単体配布用バイナリに埋め込む
bash tools/build.sh

# このターミナルを開いたままにする。終了は Ctrl+C
target/release/cerulean serve
```

1. PC のブラウザで **<http://127.0.0.1:8000/app/>** を開きます。
2. 起動画面で、抽出した **`.bin` ファイル**を選びます（ダウンロードした `.msi` ではありません）。
   画面サイズは既定の「自動」でファイル名から判定します。合わない場合だけ変更してください。
3. 起動操作後、Today 画面が出るまで待ちます。初回は数十秒以上かかります
   （端末・ブラウザにより変わります）。途中では進行状況と Windows Mobile の起動画面が表示されます。
4. 画面をクリック・タップして操作します。方向キー・Enter と画面外のボタンも使えます。
   PC で英数字を入力するときは IME をオフにしてください。

起動後は状態が自動保存され、次に開くと「続きから再開」できます。音はメニューの
「音を出す」でオンにします（既定はオフ）。詳しくは以下のブラウザ版の使い方を参照してください。

## インターネットを使う

Windows Mobile 内からインターネットに接続するには、中継サーバーが必要です。
次のコマンドで、ブラウザ版の配信と中継サーバーを一緒に起動できます。

```sh
./cerulean serve --with-relay
```

1. 起動時に表示されるトークン付き URL をブラウザで開く。
2. Windows Mobile を起動し、CErulean のメニューで「ネットワーク（中継サーバー経由）」をオンにする。
3. Windows Mobile の「設定 → 接続 → ネットワークカード」で、接続先を「インターネット設定」にする。
4. Windows Mobile の Internet Explorer で Web サイトを開く。
   HTTPS サイトを使う場合は、先に `http://10.0.2.2/` を開き、CErulean Local CA の証明書をインストールする。

別の中継サーバーを使う場合は、メニューで URL とトークンを指定します。
HTTPS のページからは `wss://`（ローカルの中継は `ws://127.0.0.1`）を使います。

## スマートフォンで使う

配信された CErulean をブラウザで開きます。
抽出した `.bin` はスマートフォン内に保存し、その端末で選択してください。

iOS では、HTTPS で開かないと動作が遅くなる可能性があります。

## できること

- WM5: Pocket PC の英語版・日本語版、日本語 VGA 版
- WM6: Professional Images の日本語版に含まれる Classic 構成、日本語の電話つき VGA 構成
- Today 画面までの起動、標準アプリの操作、対応する CAB / EXE の追加インストール
- 画面のタップ・ドラッグ、方向キー・Enter・英数字・App ボタンの入力
- 自動保存・手動保存、続きから再開、スナップショットの読み込み・書き出し
- イメージや画面サイズごとのプロファイル切り替え、ホーム画面への追加（PWA）、オフライン起動
- ゲストの音声再生（等速時）、端末の時刻との同期
- ストレージカードの作成・挿抜と、ホストとのファイルの出し入れ
- CLI でのスクリプト実行・操作の記録と再生、画面の PNG 出力・音声の WAV 出力、フォルダ共有
- 中継を使った IPv4 の TCP 通信、DHCP・DNS、IE Mobile の HTTP / HTTPS 接続
  （HTTPS はゲスト側へ専用 CA の導入が必要。下のネットワークの説明を参照）
- ブラウザ内での JIT-to-wasm（既定で有効。メニューでインタプリタへ切り替え可能）
- 単体バイナリによる Web 配信、または静的ファイルだけでの配信

## できないこと・制限

- 実機用 ROM、Windows Phone、デスクトップ版 Windows の起動。対応構成は Device Emulator 用の S3C2410 系です。
- 通話・SMS・携帯回線の利用。電話つきイメージでも通信モデムは実装していません。
- ブラウザから中継なしで行うゲストのインターネット通信。静的配信だけならネットワーク機能はオフで使います。
- IPv6、DNS 以外の UDP、外向きの ICMP、外部からゲストへの接続（サーバー用途）。
- 本体ソフトキー（VK_F1/F2）・電源ボタンの入力。ソフトキーは画面上のボタンをタップして代用します。
- `.msi` の直接読み込み。事前に `.bin` を抽出してください。
- 複数タブでの同時実行、記録中の強制終了後の記録の継続。保存状態からの再開はできます。
- すべてのアプリ・周辺機器の動作保証。音は早送り・2 倍・最高速では鳴りません。

## 保存と困ったとき

イメージと保存状態はブラウザ内のストレージ（OPFS）に保存します。イメージを選んだだけでは
外部へ送信しません。サイトデータを消すと保存も失われるので、残したい状態はメニューから
書き出してください。**スナップショットには OS イメージの内容も含まれるため、公開共有しないでください。**

- ビルドで wasm-bindgen の版が合わない場合は、上記の指定版を入れ直します。
- 保存が使えない場合は、PC では `http://127.0.0.1` / `http://localhost` で開いてください。
  スマートフォンなど別端末から利用するには HTTPS での配信が必要です。下の配信設定例を参照してください。
- 画面の大きさがおかしい場合は、イメージに対応する解像度を起動画面で指定します。
- 2 つ目のタブは待機します。先に開いているタブを閉じてください。

## 配信方法

### 単体バイナリで配信する

`tools/build.sh` で作った `target/release/cerulean` を、好きな場所にコピーして使えます。
HTML・JS・wasm を隣に置く必要はありません。ビルド時に使った Web 資材が埋め込まれており、
実行したディレクトリに影響されません。

```sh
./cerulean serve                 # http://127.0.0.1:8000/app/
./cerulean serve --with-relay    # 同じポートの /relay にゲストのネットワーク中継も置く
```

`--port N`（127.0.0.1）・`--listen 0.0.0.0:8000`（他の端末から）を指定できます。
Web 資材の変更を試すときは `--root web/www` で外部ファイルからの配信に切り替えます。
`--with-relay` を付けると中継も動き、起動時に表示される `…/app/#relay-token=…` を開くと
トークンが入ります。中継の URL は既定で「このサイトの /relay」なので、メニューで
ネットワークをオンにするだけです。中継は既定で私的アドレス（LAN・localhost 等）へは
つながず、`--allow-private` で許可できます。`--token` でトークンを固定できます。

### 静的ファイルだけで配信する

**ゲストのネットワーク中継が不要なら、通常の静的 Web サーバーだけで動きます。**
エミュレーション・入力・保存・音声はブラウザで処理するため、CErulean のサーバーを
常時動かす必要はありません。

```sh
# 埋め込んだものと同じ Web 資材を、新しいディレクトリへ書き出す
./cerulean web-export site
```

生成された `site/` の中身を、そのまま Web サーバーの公開ディレクトリに置きます。
**`app/` と `pkg/`（中の `snippets/` も含む）の両方が必要**です。
サイトの `/app/` を開きます。`/demo/app/` のようなサブディレクトリへの配置もできます。
OS イメージは公開ディレクトリに置かず、利用者がブラウザで選択します。

自分でビルドした Web 資材を配信する場合は、`bash tools/web-build.sh` の後で
`web/www/index.html`・`web/www/app/`・`web/www/pkg/` を同じ構成でコピーしても使えます。

配信は **HTTPS** にし、`.wasm` の Content-Type を **`application/wasm`**、`.js` を
**`text/javascript`** に設定してください。ローカル確認では `http://localhost` も使えます。
`file://` で HTML を直接開く方法には対応していません。ネットワーク機能は既定のオフのままで
使ってください。Windows Mobile 内からインターネットを使う場合は、中継サーバーが必要です。必要になったら `./cerulean relay` を別に用意し、その URL とトークンを設定できます。

### HTTPS と中継をまとめて配信する

公開する（TLS はリバースプロキシで付ける）例。Caddy は WebSocket もそのまま通すので、全部を 1 つの
ポートに流すだけでよい:

```
cerulean.example.net {
    reverse_proxy 192.168.1.11:8000     # cerulean serve --listen 0.0.0.0:8000 --with-relay --token 長いトークン
}
```

https のページでは OPFS・SubtleCrypto が使え、中継には自動で `wss://…/relay` でつなぐ。公開するときは
トークンを長くし、必要なら `/relay` を IP で絞る（Caddy の `remote_ip`）。計測ページ（bench）は
`tools/serve-bench.py 8000`（`http://localhost:8000/web/www/app/` でもアプリが開ける）。

## ブラウザ版の詳しい使い方

イメージを選ぶと Today まで最高速で起動し（端末により数十秒以上）、着いたら自動で
保存して、以後は等速で動く。Windows Mobile のスプラッシュが出るまで（ゲストの画面が真っ暗な間）は、
進み具合とカーネルのデバッグ出力を描いたブート画面を見せる。画面のタップ（マウス・タッチ）、画面の下（横向きでは右）の
ボタン（方向キー・決定・App1〜5）、PC のキー（矢印・Enter・英数字・F1〜F5 = App1〜5 など。
IME は切る）で操作する。

- 保存: イメージとスナップショットは端末の OPFS に置く（外部に送らない）。自動保存は
  3 世代（Today 到着時・画面を離れたとき・操作があれば 30 秒ごと・なければ 5 分ごと）。
  次に開くと「続きから再開」が出る。メニューから手動保存・書き出し（.snap.gz）・読み込み。
  **書き出したスナップショットにはイメージの中身が入る**ので公開の場で共有しないこと。
- 記録: メニューの「記録開始」で起点スナップショットを取り、「記録停止」で入力の
  スクリプト（絶対命令数）を作る。書き出した 2 つを CLI で再生すると同じ状態になる
  （スクリプトの先頭のコメントに手順と、終わりの CPU・RAM・画面の SHA-256）:
  `gunzip X.snap.gz && cerulean run --snap-load X.snap --script X.txt --result r.jsonl PPC_USA.bin`
- 音: メニューの「音を出す」でゲストの音（起動音・タップ音・通知など。IIS＋DMA）を鳴らす
  （既定はオフ。等速のときだけ鳴らし、早送り・2 倍・最高速の間は鳴らさない）。
- 時計: 保存から再開したとき・画面に戻ったとき・起動の早送りの後に、ゲストの時計を端末の
  時刻に合わせる（メニューで切れる。記録にも `rtc` コマンドとして残るので再生しても同じ）。
- プロファイル: OS・画面の大きさの違う環境（WM5 USA・WM6 JPN・VGA など）を 1 つの PWA で使い分ける。
  最初の画面で作る・切り替える・名前を変える・消す（メニューの「最初の画面へ」から）。保存・
  ストレージカード・記録はプロファイルごと、イメージは共有。切り替えると今の状態を自動保存して止め、
  切り替え先のいちばん新しい保存から再開する（動くのは 1 台だけ）。
- 動かせるのは 1 タブだけ（2 つ目のタブは待つ）。ホーム画面に追加でき、オフラインでも開ける。
